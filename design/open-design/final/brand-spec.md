# 翻盘棋视觉规格

用户本轮指定的纸张、绿呢、墨色、朱砂与黄铜色覆盖早先的视觉方向。主视觉复用用户项目提供的 1100 × 733 棋桌图片，并以内嵌 JPEG 保留完整画面。

```css
--bg: oklch(91.6473% 0.02107 88.725); /* #e9e3d4 */
--surface: oklch(94.5% 0.018 88.725);
--fg: oklch(27.4107% 0.02207 166.491); /* #1d2b25 */
--muted: oklch(46% 0.019 166.491);
--border: oklch(77% 0.026 88.725);
--accent: oklch(55.7546% 0.14536 34.034); /* #b94d35 */
--felt: oklch(38.5475% 0.05342 167.480); /* #244d3e */
--brass: oklch(68.4736% 0.09752 77.861); /* #bb9250 */
--display: "Songti SC", "STSong", "Noto Serif CJK SC", Georgia, serif;
--body: "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
--mono: "SFMono-Regular", Consolas, monospace;
```

1. 暖纸为背景，以深绿棋盘为唯一主要触感焦点，朱砂只用于印章、错误与爆破状态。
2. 宋体负责标题和比分，正文使用清晰黑体；中文标题行高 1.35–1.4，无负字距。
3. 细线、方角和章序建立棋谱结构，只有原生手机外框与底部浮层使用明显圆角。
4. 木框、绿呢、黑色亮面和象牙棋子呈现桌面实物感；动效集中在落子与翻转。
5. 手机端始终只有一个产品界面，桌面用对弈手册侧注承接留白。
