# 翻盘棋 · 原型设计说明

入口为 `index.html`。单个 HTML 内嵌全部样式、逻辑、图标、纸纹与用户提供的棋桌 JPEG；无需外部库、字体或图片请求。原有 `reversi-friends.html` 保留，另存 `reversi-friends-v2.html` 作为改版前副本。

视觉以暖纸、深绿棋桌和宋体棋谱为核心，朱砂用于小印与爆破反馈，黄铜用于能量和落点提示。390 × 844 为主要构图，1440 × 900 保留一个手机产品界面并提供对弈手册侧注；320 × 568 的对局页压缩棋盘与间距，内容页可在手机内部纵向滚动。

交互骨架按微信小程序重排：顶部是 44px 状态栏（桌面演示显示 9:41 与信号，真机隐藏并让出安全区）和 44px 居中标题栏，右上角为胶囊「更多 / 收起」；底部在棋桌、棋谱、章节三个主页面显示三项 tabBar，进入模式、对局、房间、加入与结算后让位给返回键。页面按层级推入与退回，返回键、Esc 与左缘右滑共用同一套离开确认。

| 状态 | 进入方式 | 主要操作与下一状态 |
| --- | --- | --- |
| 棋桌首页 | 默认入口、底部「棋桌」 | 开始一局 → 模式选择；邀请好友 → 创建房间；房间号 → 加入；底部切换到棋谱与章节。未完成的棋局可继续。 |
| 模式选择 | 开始一局、棋友 | 好友棋桌 / 独自练习 / 同屏切磋；选择经典或技能规则；练习提供入门、进阶、高手。三组单选均可用方向键切换。 |
| 对局 | 开始练习、同屏入座、房主开局 | 点合法光点 → 落子、翻转、反馈、换手；无法落子自动让手；双方无落点 → 结算。 |
| 技能列表与详情 | 对局下方的技能名称 | 查看规则 → 装配 → 发动；十字爆破与蓄势需继续点合法格，洞察直接标出建议落点。 |
| 好友房间 | 邀请好友、创建好友房 | 随机生成六位数字 → 等待入座；分享预览、复制邀请或另一窗口加入；双方连接后由房主开始。 |

| 声音与动效 | 胶囊「更多 → 设置与偏好」、对局工具栏 | 独立切换声音、动效与振动（振动覆盖落子、tabBar 与胶囊）；调整音量；保存本机偏好，关闭浮层回到原状态。 |

## 小程序式骨架

- 标题栏三件套固定为「返回 / 标题 / 胶囊」三列，不随返回键显隐而移动；标题 17px 居中，胶囊内是「更多」与「收起」。收起在首页直接给反馈，在对局中先确认再收起。
- tabBar 只属于三个主页面：棋桌、棋谱、章节。图标在上、10px 标签在下，当前项用深绿，不再使用下划线或圆点。对局、房间、加入与结算隐藏 tabBar，避免误触离开棋局。
- 页面层级为 tab 根 0、模式 1、对局 / 房间 / 加入 2、结算 3。进入用 push，返回用 pop，tab 之间横移；动画只作用于当前页，时长 280–300ms。左缘 26px 起手、横向超过 72px 的滑动等同返回键。
- 浮层分三种：底部浮层（规则、技能、回放、设置）、居中对话框（认输、收起小程序、离开棋桌、替换当前棋局）与底部 action sheet（更多菜单）。对话框最大 300px、左右双按钮，危险操作用朱砂；action sheet 为 56px 行高的分组列表加独立取消。两者隐藏标准标题栏，用 `aria-label` 保留可访问名称。
- 轻提示改为屏幕中央的深色小圆角块，停留 2.4 秒；主按钮 48px 高、8px 圆角，次按钮纸面底，设置开关 46 × 28，列表行 44–56px。
- tabBar 与胶囊点按时给一次 8ms 轻振动，受「轻触振动」控制并默认开启；图标同时做短促回弹：tabBar 图标上浮回弹、选中项描边加粗，胶囊「更多」三点轻推、「收起」圆点收拢回转。关闭动效或系统「减少动态效果」时只保留振动；按下瞬间有 scale(.84–.86) 的按压态。
- 对局里的落子格在按下时把铜点放大成当前手方的棋子预览，抬手给 8ms 轻振；这一手的落子音效不再重复振动，AI 与好友的落子仍保留 12ms，爆破仍保留 [15, 35, 20] 的节奏。悔棋、技能选择、装配与发动都给 8ms 轻振和 200ms 的回弹，禁用按钮不触发；关掉动效只停回弹，关掉振动才彻底安静。

## 规则与技能

- 标准开局：D4、E5 为白，E4、D5 为黑；黑先行，合法首手为 D3、C4、F5、E6。
- 经典模式严格使用八方向夹子规则；双方都无处落子时结束，允许棋盘未填满即终局。
- 技能局双方初始能量为 3，每次落子获得 1，上限 6。十字爆破消耗 3，在普通翻子后额外翻转落点上下左右紧邻的敌子；洞察消耗 2，每回合限用一次；蓄势不消耗能量，下一手额外加 2，每位棋手每局一次。
- 普通落子有黄铜色扩散环；爆破另有朱砂十字与圆环。翻子分段错开，上一手以小印标记；关闭动效或开启系统减少动态效果后，保留状态信息。

## 邀请边界

房间通过同一来源的浏览器本地存储与广播同步，房主校验落点、回合与状态版本；第三位访客无法入座。邀请有效期为十分钟。房主关闭棋桌后，访客会收到离席反馈；访客断连后，棋局暂停等待。房主选择再来一局时，双方返回新棋盘。

微信入口展示真实的交接预览，明确说明没有打开微信、没有发送消息；复制完成也只提示文案已复制。**尚未接入微信分享和跨设备实时服务**，本地演示请用房间内的“在另一窗口加入”。没有伪造好友入座、微信成功发送或玩家战绩。

## 交互与验证

- 常规按钮与开关提供至少 44px 操作区域、焦点轮廓、按下与禁用状态；棋盘作为 8 × 8 密集游戏区域等比缩放，支持合法格键盘导航。
- 键盘对局中，落子或等待 AI 应手后焦点会回到离上一手最近的合法格，方向键继续在合法格之间移动；方向键只在同一行或同一列推进，到边界即停，不会跳到下一行。鼠标落子不抢焦点。棋盘焦点环使用象牙色，避免与黄铜落点混淆。
- 换页后焦点落到新页面标题（进入对局时落到第一个可落子的格子），读屏因此能读到新页面；各页面记住自己的滚动位置，返回棋谱时回到原处。标题栏与 tabBar 随页面层级显隐，当前 tab 用 `aria-current="page"` 标记，返回键在 tab 根页隐藏。
- 返回键、Esc、左缘右滑都走 `confirmBack`：对局未结束先问是否回首页，好友房先问是否收起棋桌，从棋谱打开的结算先回棋谱原位置。
- 底部浮层标题栏固定、正文独立滚动；可从把手或标题处下滑关闭，点击遮罩与 Esc 关闭时带 180ms 退场，关闭后焦点回到打开它的控件（鼠标点击与键盘 Enter 都记下来源），Tab 在浮层内循环。嵌套打开技能详情不会丢失原来的焦点来源。退场期间遮罩不再拦截点击与按键，关闭动效时直接完成退场；因此从浮层跳到新页面后可以立即操作。居中对话框与 action sheet 共用同一套焦点归还与退场逻辑。
- 加入房间页自建数字键盘：物理键盘的数字与退格在任何焦点位置都可用，Enter 只提交一次；连接房主期间输入与数字键禁用，避免重复提交。触屏设备上隐藏系统键盘，避免顶起布局。
- 结算页的「逐手回看」把棋谱还原成可走动的棋盘：开局 / 上一手 / 下一手 / 终局四个按钮、进度滑块、左右方向键与 Home / End 都能换手；当前一手以黄铜内框标在棋盘上，落子记录逐行高亮并自动滚到可见处，点任意一行可跳到那一手。回放不额外存 40 份棋盘，只按每手的落子与翻转在打开时重算 64 格。
- 悬停底色在暖纸上加深约 8%，足以辨认且不降低文字对比，图标按钮、文字按钮、分段控件与底栏一致；触屏设备不保留 hover 状态。棋谱行首印章、设置开关、复制按钮都有独立的悬停或成功反馈。
- 鼠标悬停或键盘聚焦合法格时显示本方棋子的虚影，铜点淡出，落子前就能看清颜色；触屏不启用悬停虚影。
- 好友房每 3 秒心跳一次，但只在内容变化时写 DOM；房间状态、回合文案与落子反馈不会重复触发读屏播报。
- 房间页邀请剩余时间按分钟更新；复制成功后按钮短暂显示“已复制，可粘贴”。从历史棋谱点“再来一局”会沿用该局的模式、难度与规则，好友房记录则引导重新开桌。
- 音效使用浏览器音频能力；振动在设备支持时生效：人手落子、tabBar、胶囊、悔棋与技能按钮为 8ms，AI 或好友的落子为 12ms，爆破为 [15, 35, 20]；三种偏好相互独立。系统减少动态效果始终优先，关闭动效时界面动画停止但轻振动保留。
- 已检查脚本语法、首手与翻子、三档 AI、技能消耗与限次、悔棋、终局与认输、记录去重、邀请错误、满员拦截、双窗口落子同步、离席和再开局。另用 120 局随机完整棋局验证棋子总数与终局不变量。
- 回放重建用 300 局随机完整棋局（近 1.8 万手，含两千余次十字爆破的额外翻转）逐手比对：第 k 手后棋子总数为 4 + k，末态与实盘完全一致。
- 第二轮交互回归用两组 DOM 桩共 79 项断言：换页焦点与返回来源、单选组方向键、棋盘方向键不跨行、完整练习局到结算存档、同屏悔棋、技能装配与消耗、好友房建房 / 入座 / 开局 / 双方落子、加入房间数字键、浮层开合与焦点归还、锁定章节提示；未发现脚本异常。
